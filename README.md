# openwrt-blocklist-update

## Development

Use `make`:

- `make` - install development dependencies and run checks
- `make test` - run test
- `make check` - perform static code analysis
- `make dist` - prepare distribution artifacts from the latest commit
- `make clean` - remove distribution artifacts
- `make release` - tag the latest commit as a new release of CLI
- `make info` - print system info (useful for debugging).
